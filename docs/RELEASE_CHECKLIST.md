The owner selected a separate public UTM repository. Only the tracked UTM snapshot was copied; the original repository history and Android branch were not imported.

- MIT license and maintainer attribution retained.
- English/Turkish guides, contribution rules, issue/PR templates and six starter tasks included.
- Run `npm ci`, `npm test`, and `npm run build` before tagging.
- Verify GitHub Actions, Pages demo and issue form files after pushing.
- Publish v0.1.0 from the tested main commit.
- No dedicated confidential mailbox is promised; see SECURITY.md.
